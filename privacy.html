Privacy Policy

Rclone File Manager

Last updated: September 28, 2026

1. 概要

Rclone File Manager は、利用者自身の Windows PC 上で動作する個人利用向けファイルマネージャです。ローカルストレージおよび利用者が設定したクラウドストレージへアクセスするために rclone を使用します。

2. Google ユーザーデータへのアクセスと利用

利用者が Google Drive を接続した場合、本アプリケーションは Google OAuth により利用者が許可した範囲で Google Drive データへアクセスします。

アクセス対象には、ファイルおよびフォルダーの一覧、名前、サイズ、更新日時その他のメタデータ、ならびに利用者が明示的に実行したファイル操作に必要なファイル内容が含まれる場合があります。

これらの Google ユーザーデータは、利用者にファイル管理機能を提供する目的にのみ使用します。

3. 保存

Google Drive 接続用の OAuth 認証情報は、rclone により利用者の PC 上のアプリケーション専用設定ファイルへ保存されます。ファイル管理に必要な情報が利用者の PC 上へ一時的または継続的に保存される場合があります。

Google ユーザーデータや OAuth 認証情報を、開発者が運営する外部サーバーへ送信・保存する仕組みはありません。

4. 共有・販売・広告利用

Google ユーザーデータを広告目的で使用せず、第三者へ販売しません。

利用者が要求したクラウドストレージ操作を実行するために必要な通信を除き、Google ユーザーデータを第三者へ共有しません。

5. データの削除とアクセス権の取り消し

本アプリケーションは開発者側のサーバーへ Google ユーザーデータを保持しません。

利用者の PC 上に保存された接続設定や認証情報は、該当する rclone remote またはアプリケーション設定を削除することで削除できます。また、Google アカウント側から本アプリケーションへのアクセス権を取り消すこともできます。

6. Google API Services User Data Policy

Rclone File Manager が Google APIs から受け取った情報の使用および他アプリへの転送は、Limited Use requirements を含む Google API Services User Data Policy に従います。

7. ポリシーの変更

本アプリケーションの機能またはデータの取り扱いが変更された場合、この Privacy Policy を更新します。
