Rclone File Manager

Personal Windows file manager powered by rclone

概要

Rclone File Manager は、ローカルストレージとクラウドストレージを扱うための個人利用向け Windows ファイルマネージャです。

Google Drive、OneDrive、Dropbox などのクラウドストレージとの通信には rclone を使用します。

Google Drive へのアクセス

Google Drive への接続は、利用者自身が Google OAuth で許可したアカウントに対してのみ行われます。

Google Drive のファイルやフォルダーの表示、および利用者が明示的に実行するファイル操作のために、必要な範囲で Google Drive データへアクセスします。

Google Drive データや OAuth 認証情報を、開発者が運営する外部サーバーへ送信・保存する仕組みはありません。
